Available On

Tech Stack

My Role & Contribution

Integrated Mapbox for turn-by-turn navigation to guide dog walkers along specific routes, including adding custom markers for actions like dog 'pop' and 'pee.' Implemented the Mapbox functionality in pure Swift and exposed it to a React Native app via a Native Module, enabling seamless communication between the native iOS code and JavaScript layer while maintaining high performance and full access to Mapbox SDK features.
